Como ler

  • Classe você aplica num elemento (class="...").
  • Ajuste global não depende de classe sua: muda um componente do PrimeNG (ou um elemento HTML) no sistema todo.
  • Biblioteca externa ajusta componentes de outra biblioteca.
  • no elemento a regra estiliza o próprio elemento que recebe a classe; dentro estiliza algo dentro dele (ex.: o botão dentro de .btn-search).
  • Valores riscados foram declarados antes e sobrescritos; o valor que vale aparece em destaque.
  • Problema muda o que aparece na tela de um jeito provavelmente não intencional. Organização é repetição sem efeito visual.
